# GoalFocus / 专注目标桌面小工具（Windows）

GoalFocus is a minimalist desktop productivity tool for Windows.  
It helps users turn a long-term goal into a current goal and a set of key actions, then stay focused with a floating desktop focus card.

GoalFocus 是一个运行在 Windows 桌面的极简效率工具。  
它帮助用户把长期目标拆解为当下目标和若干关键动作，并通过悬浮在桌面的“专注卡片”持续提醒和陪伴执行。

---

## Overview / 项目简介

GoalFocus is designed for people who already know what they want to do, but still struggle with distraction, hesitation, or startup friction.

Instead of only recording time, GoalFocus keeps the current goal visible on the desktop and helps the user move from planning to execution.

GoalFocus 面向这样一类用户：他们并不是没有目标，而是在真正执行时，容易分心、犹豫，或者启动成本过高。

它不是一个单纯“计时”的工具，而是把用户当前最重要的目标直接放到桌面上，让计划更容易转化为行动。

---

## Core Idea / 核心思路

Users first define:
- one long-term goal
- one current goal
- several key actions

Then GoalFocus displays a floating focus card on the desktop to keep the current task clear and actionable.

When a key action is completed, the product provides a lightweight sense of progress and positive feedback, helping reduce resistance and improve continuity.

用户先设定：
- 一个长期目标
- 一个当下目标
- 若干关键动作

随后，GoalFocus 会通过悬浮在桌面的专注卡片，把当前任务持续保持在视野中。

每完成一个关键动作，产品都会给出轻量的进度反馈和正向强化，帮助用户降低阻力，维持连续行动。

---

## What Problem It Solves / 它解决什么问题

Many productivity tools focus on organizing information, but users still need extra effort to decide:
- what matters most right now
- what the next step is
- how to stay on one thing long enough to finish it

GoalFocus focuses on the execution layer:
- keeping the current goal visible
- reducing switching costs
- turning goals into concrete action steps
- making focused work easier to start and sustain

很多效率工具更偏向“信息整理”，但用户真正卡住的往往是：
- 此刻最重要的是什么
- 下一步到底要做什么
- 如何在一件事上持续停留，直到做完

GoalFocus 更聚焦在“执行层”：
- 让当前目标始终可见
- 降低注意力切换成本
- 把目标转化为具体动作
- 让专注这件事更容易开始，也更容易持续

---

## Features / 主要功能

- 长期目标与当下目标设定  
- 关键动作拆解  
- 桌面悬浮专注卡片

## Why I Built This / 我为什么做这个项目

I wanted to build a desktop tool that supports execution, not just planning.

Many people do not fail because they lack ambition. They fail because the path between intention and action is too weak. GoalFocus is my attempt to make that path shorter, clearer, and more concrete.

我想做一个真正服务于“执行”的桌面工具，而不只是帮助用户做计划。

很多人不是没有目标，而是“从想做”到“真的开始做”之间的链路太脆弱。GoalFocus 是我对这个问题的一次产品化尝试：让这条链路更短、更清楚、更具体。
